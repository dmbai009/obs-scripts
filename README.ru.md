# Lua-скрипты для OBS Studio

Два небольших дополнения для **OBS Studio**: звук при сохранении повтора и сохранение таймкодов трансляции или записи.

[English](README.md) · [Лицензия MIT](LICENSE)

</div>

## Что внутри

| Скрипт | Назначение | Дополнительные требования |
| --- | --- | --- |
| [`replay_save_sound.lua`](replay_save_sound.lua) | Проигрывает выбранный звук после сохранения повтора (Replay Buffer) | Нет |
| [`timestamp.lua`](timestamp.lua) | Сохраняет таймкоды по горячей клавише со смещением времени и настраиваемым именем файла | `yt-dlp.exe` только для автоматического определения названия стрима в Windows |

Оба файла — обычные Lua-скрипты для встроенной системы скриптов OBS, а не отдельные программы или DLL-плагины.

## Установка

1. Скачайте нужный `.lua`-файл из репозитория.
2. В OBS откройте **Инструменты → Скрипты** (*Tools → Scripts*).
3. Нажмите **+** и выберите файл.
4. Настройте параметры появившегося скрипта.

Отдельно устанавливать Lua не нужно. После добавления в OBS не перемещайте исходный `.lua`-файл.

## Звук сохранения повтора

[`replay_save_sound.lua`](replay_save_sound.lua) воспроизводит уведомление, когда OBS сообщает об успешном сохранении клипа из буфера повтора.

- Выберите звуковой файл (WAV, MP3, OGG, FLAC и другие поддерживаемые OBS форматы).
- Установите громкость от **0 до 100%**.
- Кнопка **«Проверить звук»** позволяет прослушать уведомление.
- Звук проигрывается через приватный Media Source и не появляется в списке источников сцены.
- Уведомление направляется на **устройство мониторинга OBS**, а не напрямую на аудиодорожки трансляции или записи.

**Важно:** если OBS одновременно захватывает звук рабочего стола с того же устройства, уведомление **всё равно может попасть в запись** через захват системного звука. Устройство мониторинга выбирается в **Настройки → Аудио → Дополнительно → Устройство мониторинга**.

Необходимо включить и запустить буфер повтора. Обычное завершение записи не вызывает это уведомление.

## Таймкоды

[`timestamp.lua`](timestamp.lua) дописывает таймкод в текстовый файл при нажатии горячей клавиши во время стрима или записи.

### Настройка

1. Добавьте скрипт через **Инструменты → Скрипты**.
2. Задайте **«Смещение времени (секунды)»**. По умолчанию **−30 секунд**.
3. Выберите **«Папка для таймкодов»**. По умолчанию — рабочий стол.
4. Выберите режим имени файла:
   - **Автоматически по ссылке** — взять название активного стрима через `yt-dlp.exe` (только Windows и только во время стрима).
   - **Название вручную** — использовать указанное название.
   - **Только дата** — сохранять с префиксом `stream_timestamps`.
5. В **Настройки → Горячие клавиши** назначьте кнопку действию **«Сохранить таймкод»**.

Пример содержимого файла:

```text
00:12:34
00:28:07
01:03:51
```

Имя файла имеет формат `<название>_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.txt`. Недопустимые для Windows символы удаляются. Повторное нажатие в течение **500 мс** игнорируется. Смещение применяется к прошедшему времени трансляции или записи, отрицательный результат становится нулём. Если запущены и стрим, и запись, используется время стрима.

### Автоматическое название трансляции

- Скачайте `yt-dlp.exe` из [официальных релизов](https://github.com/yt-dlp/yt-dlp/releases).
- Укажите путь к нему в настройках скрипта, поместите рядом со скриптом или добавьте в `PATH`.
- В поле **«Ссылка на канал или эфир (для авто)»** вставьте адрес трансляции или канала.
- Скрипт использует `yt-dlp` **только для получения названия**, видео не скачивается.
- Название определяется в фоне. При успешном определении файл таймкодов переименуется.
- Если название получить не удалось, таймкоды всё равно будут сохраняться: под вручную указанным запасным названием либо `stream_timestamps`.
- Поддержка конкретных сайтов зависит от `yt-dlp`. На других ОС можно использовать ручное название или режим даты без `yt-dlp`.

## Дополнительно

- Интерфейс настроек скриптов — на русском языке.
- Совместимость со всеми версиями OBS Studio не проверена. Требуется OBS с поддержкой Lua-скриптов.
- Скрипты не связаны с OBS Project и не являются официальными дополнениями.
- В исходниках нет личных настроек, сохранённых каналов или учётных данных: свои ссылки и пути вы вводите локально в OBS.
